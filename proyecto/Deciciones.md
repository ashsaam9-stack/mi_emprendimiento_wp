## 2. Páginas Seleccionadas para la Fase 1 (5 pts)
Para esta primera etapa de construcción (excluyendo pagos y carrito por ahora), se configurarán las siguientes 5 páginas:
1. **Inicio:** Es la carta de presentación principal del estudio para captar la atención de las clientas.
2. **Contacto:** Permite que se comuniquen de forma directa a través de un formulario integrado.
3. **Servicios:** Detalla los diferentes tipos de extensiones de pestañas y tratamientos disponibles.
4. **Sobre mí:** Muestra la historia, experiencia y profesionalismo detrás de STUDIO ASH.
5. **Blog:** Espacio destinado a compartir consejos de cuidado posterior y tendencias.

## 3. Plan del Tema (5 pts)
* **Nombre del tema custom:** `studio-ash-theme`
* **Tipo:** Tema propio (Custom) desarrollado desde cero.
* **Justificación:** Se optó por un tema propio para asegurar que la identidad visual, la paleta de colores y la estructura de componentes definida en el Parcial 2 se reflejen exactamente sin código basura o plantillas pesadas innecesarias.
* **Carta Gantt simplificada:**
  * *5 al 10 de Noviembre:* Investigación y elección de plugins / Creación de estructura base.
  * *11 al 17 de Noviembre:* Desarrollo del tema custom e integración de páginas.
  * *18 de Noviembre:* **Checkpoint (Entrega intermedia).**
  * *19 al 24 de Noviembre:* Pruebas finales, optimización y ajustes estéticos.
  * *25 de Noviembre:* **Entrega final y publicación del sitio.**

## 4. Plan B / Gestión de Riesgos (5 pts)

| Riesgo Detectado | Acción Correctiva (Plan B) | Cuándo se activará |
| :--- | :--- | :--- |
| **Incompatibilidad de un plugin** con el tema custom o con otra herramienta. | Desactivar el plugin afectado y buscar una alternativa ligera en el repositorio oficial que cumpla la misma función. | Si genera un error crítico de pantalla blanca o rompe el diseño base. |
| **Retraso en la codificación** del tema propio debido a errores de estilos CSS. | Utilizar un tema base predeterminado estructurado (como el tema oficial del curso) temporalmente para estructurar el contenido. | Si al 15 de noviembre el desarrollo del tema custom presenta un bloqueo mayor a 24 horas. |
| **Problemas de visualización** responsiva en dispositivos móviles. | Ajustar las reglas de media queries en el CSS principal y revisar las unidades relativas (Flexbox/Grid). | Durante las pruebas de usabilidad previas al checkpoint. |
